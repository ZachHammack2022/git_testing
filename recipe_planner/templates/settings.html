One-time Google setup
  1. In Google Cloud Console, create a project and enable the Google Calendar API.
  2. Under APIs & Services, set up the OAuth consent screen (External, add yourself as a test user), then set its publishing status to In production. Otherwise Google signs you out every 7 days.
  3. Create Credentials → OAuth client ID of type Web application, with this redirect URI: {{ redirect_uri }}
  4. Stop the app and start it with GOOGLE_CLIENT_ID=... GOOGLE_CLIENT_SECRET=... ./run.sh, then come back here and press Connect. Google will warn the app is unverified; that's expected for your own app.
